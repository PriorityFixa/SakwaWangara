# Sakwa Wangara | Executive & Corporate Trainer

Professional corporate training website for **Sakwa Wangara**, an Executive & Corporate Trainer specialising in professional etiquette, customer service, interpersonal skills and workplace communication.

## 🌐 About the Project

This website presents Sakwa Wangara's professional training services and provides organisations with an easy way to learn about his programmes and request a training session.

The website focuses on a clean, modern and premium corporate presentation designed to build credibility and encourage organisations to get in touch.

## 🎯 Core Message

> **Building professionals who serve with excellence.**

The website communicates a practical approach to professional development, helping individuals and organisations turn training into workplace behaviour and improved customer experiences.

## 📌 Training Services

## 🚀 Running the Website Locally

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Open the project folder:

```bash
cd sakwa-wangara
```

Then open `index.html` in a browser.

For development, using VS Code with the **Live Server** extension is recommended.
